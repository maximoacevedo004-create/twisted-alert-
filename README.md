<h2>¿Cómo se forma un tornado?</h2>
<p>
Los tornados se forman cuando una tormenta muy intensa produce aire cálido y húmedo que choca con aire frío y seco. 
La diferencia de temperatura y el viento crean una rotación que puede extenderse hasta tocar el suelo, formando el tornado.
</p>

<h2>Equipo TWISTEX</h2>
<!-- Reemplaza por la imagen que quieras -->
<img src="https://TU-IMAGEN-DE-TWISTEX.jpg">
<p>
TWISTEX (Tactical Weather Instrumented Sampling in Tornadoes Experiment)
fue un proyecto dedicado al estudio de tornados utilizando instrumentos científicos
instalados cerca de las tormentas para recopilar datos importantes.
</p>
<h3>Vehículos utilizados</h3>
<ul>
<li>Camionetas modificadas.</li>
<li>Vehículos de persecución con radares.</li>
<li>Autos preparados para transportar instrumentos científicos.</li>
</ul>
